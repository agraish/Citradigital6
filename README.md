# Citradigital6

Mini project pengolahan citra digital untuk deteksi keberadaan tanda tangan.

## Struktur Project

- `dataset/present/` — dataset gambar dengan tanda tangan
- `results/` — hasil pengolahan citra
- `src/` — source code
- `requirements.txt` — library yang digunakan

## Teknologi

- Python
- OpenCV
- NumPy
